# Ankur Trust — Static HTML Copy

This folder is a static HTML version of the PHP website. It is separate from the original project, which remains unchanged.

## Open the site

Open `index.html` in a browser, or serve this folder with VS Code Live Server. No PHP installation is needed.

Bootstrap 5.3.3 and the Google Fonts are loaded from CDNs, so an internet connection is needed for those external assets. The site's own styles, JavaScript, and logo are included in this folder.

## Pages

- `index.html` — Home
- `about.html` — About Us
- `pvtg-connect.html` — PVTG Connect
- `projects.html` — Projects
- `get-involved.html` — Get Involved
- `reports.html` — Reports
- `news.html` — News
- `contact.html` — Contact Us
- `donate.html` — Donate

## Static-site limitations

The contact form is only a front-end form in this copy and does not deliver messages. Use the original PHP project for working contact submissions, or connect a form backend. The pages retain the content and links available in the PHP project; some pages are still marked as coming soon there.
